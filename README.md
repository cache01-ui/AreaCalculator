# Task 3: Geometric Area Calculator

Консольний калькулятор для обчислення площі геометричних фігур (квадрат, круг, прямокутник, трикутник) за введеними параметрами користувача.

## Підтримувані фігури та формули
- **Квадрат:** `S = side^2`
- **Круг:** `S = Pi * R^2`
- **Прямокутник:** `S = a * b`
- **Трикутник:** `S = (a * h) / 2`
